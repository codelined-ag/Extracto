# components/ui

All files here are vendored from the [shadcn/ui](https://ui.shadcn.com) registry (new-york style, neutral base).

They are intentionally co-located rather than installed as a package so they can be customized without a fork.
Do not treat these as project-specific shared components — they are registry copies.
See `components.json` at the repo root for the shadcn configuration.
